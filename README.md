## Overview

Vorace is a second-year Creajeux team project built in C with CSFML. You play as a pirate who has lost everything and sets out to reclaim what is rightfully his.

Each run combines fast 2D combat with a card-based progression system. Players choose upgrades, discover interactions and navigate a tile-based procedural map that changes the rhythm of every attempt.

## Gameplay

- Responsive movement and close-range combat.
- Sprite-sheet animations for player actions and feedback.
- Card choices that modify the current run.
- Entity interactions and environmental encounters.
- Tile-based procedural map generation.
- A run structure built around experimentation and replayability.

## My Contribution

I worked on the systems that connect moment-to-moment action with the larger run:

- Player movement and attack logic.
- Sprite-sheet animation integration.
- The upgrade and card-selection systems.
- Interactions between the player and world entities.
- Procedural generation of the tile-based map.

This project was an early opportunity to build gameplay systems without relying on a commercial engine and to work directly with a C multimedia framework.

## Tech Stack

- C
- CSFML / SFML
- Tile-based procedural generation
- Data-driven card and upgrade systems
- Sprite-sheet animation
- Windows desktop build

## Play the Game

The repository contains a playable Windows build:

1. Download or clone the repository.
2. Keep `Vorace.exe`, the asset folders and the CSFML/OpenAL DLL files together.
3. Run `Vorace.exe`.

> The original source code is not included in this repository. It currently serves as a playable project archive and showcase.
